# Md Ayub Sheikh — Data Analyst Portfolio

An executive-grade personal portfolio website for **Md Ayub Sheikh** built with React, Vite, Tailwind CSS, Framer Motion, and Recharts in a clean, modern Light Theme.

## 🚀 Quick Start in VS Code

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start Local Development Server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Build for Production:**
   ```bash
   npm run build
   ```

4. **Preview Production Build:**
   ```bash
   npm run preview
   ```

## 📂 Project Structure

```
ayub-portfolio/
├── index.html                    # HTML entry point with metadata and fonts
├── package.json                  # Dependencies and scripts
├── vite.config.js                # Vite build configuration with chunk splitting
├── tailwind.config.js            # Custom color palette and typography
├── postcss.config.js             # PostCSS plugins
├── public/
│   ├── ayub-profile.jpg          # Authentic profile photo
│   └── Md_Ayub_Sheikh_Resume.pdf # Authentic resume PDF
└── src/
    ├── main.jsx                  # React DOM mount point
    ├── index.css                 # Custom glassmorphism, textures, and scrollbars
    ├── App.jsx                   # Main layout and modal manager
    ├── data/
    │   └── portfolioData.js      # Structured data for projects, skills, and metrics
    └── components/
        ├── Navbar.jsx            # Sticky glassmorphic navigation
        ├── Hero.jsx              # Hero with typing text, photo, and metrics
        ├── StatsBanner.jsx       # Animated counting stats banner
        ├── About.jsx             # Professional story and analytical pillars
        ├── Skills.jsx            # Categorized skills with interactive filters
        ├── Projects.jsx          # Featured projects with deep-dive modal
        ├── Experience.jsx        # Interactive career timeline
        ├── Certifications.jsx    # Education & verified certification cards
        ├── DashboardShowcase.jsx # "Data in Action" interactive charts
        ├── Contact.jsx           # Direct channels and validated contact form
        ├── Footer.jsx            # Modern footer with stack badges
        ├── ResumeModal.jsx       # Embedded resume PDF viewer & download
        └── CustomCursor.jsx      # Fluid desktop cursor tracking
```
